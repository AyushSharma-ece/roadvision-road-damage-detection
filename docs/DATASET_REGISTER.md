## 2. Dataset Diversity Coverage Analysis

- **Indian Road Conditions:** Strongly covered by **RDD2022 India** (`7,706` labeled images across Delhi/Gurugram/Haryana roads) plus the optional **Custom Indian Road Collection** protocol (`rural`, `urban`, `highway`, `village`, `concrete`, `wet`).
- **International Conditions:** Covered by **RDD2022** (`Japan`, `Czech Republic`, `United States`, `China MotorBike`, `China Drone`, `Norway`) + **CFD** + **DeepCrack** + **Pothole-600**.
- **Surface, Lighting & Defect Variations:** Audited across `38,385` labeled RDD2022 images (`14,618` undamaged zero-defect negative frames across India `4,483`, Norway `5,247`, Japan `2,606`, Czech `1,757`, China Drone `482`, China MotorBike `43`) encompassing asphalt/concrete, dry/wet roads, shadows, smartphone/dashcam/motorbike/drone angles, single and multi-defect scenes.
- **Exact Audited Instance Breakdown:** `D00` = `26,016` (`47.3%`), `D10` = `11,830` (`21.5%`), `D20` = `10,616` (`19.3%`), `D40` = `6,544` (`11.9%`).

## 3. Leakage Prevention & Integrity Rules

1. **No Unchecked Merging:** Segmentation datasets (`CFD`, `DeepCrack`, `Pothole-600`, `Crack500`) use binary pixel masks and are **never** silently mixed into 4-class YOLO bounding-box training.
2. **Duplicate Removal:** Exact MD5 duplicates are excluded before splitting; 64-bit dHash clustering + sequential filename bucketing keeps near-identical/sequential road frames in the same split (`train`, `val`, or `test`).
3. **Strict Test Isolation:** The held-out `test` split generated by `audit_datasets.py` is **never** exposed to model training or hyperparameter tuning.
